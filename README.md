# ShopMart Electronics Store

Modern AI-powered electronics shopping platform with order tracking system.

## Features
- 25+ Electronics Products (Laptops, Phones, Audio, Gaming)
- AI Product Recommendations with "AI Pick" badges
- Smart Search & Category Filtering
- Interactive 3D Animation using Three.js
- Complete Order Tracking System
- Shopping Cart with Real-time Updates
- User Account with Order History
- Responsive Mobile-First Design
- Fallback System for Images

## Technologies
- HTML5 & CSS3 (Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+)
- Three.js for 3D Graphics
- FontAwesome Icons
- Gradient Designs & Modern UI

## How to Run
1. Download or clone this repository
2. Open `index.html` in any modern web browser
3. No server setup required - runs directly in browser
